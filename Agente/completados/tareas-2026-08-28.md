# Tareas completadas 2026-08-28

## E12 — nuevo comando `db-compare`: comparación automática y precisa de BD (implementada + verificada)

- **Qué:** comando `db-compare` que compara la BD **en vivo** de un sitio contra un **dump** (VPS
  o local) o contra **otro sitio**, descubriendo **todas** las tablas automáticamente
  (`information_schema`/`SHOW TABLES`). Reemplaza el método manual (grep/awk/zcat) del incidente
  27/08. Modo ligero (`--no-tmp-container`: conteos+hash) y modo completo (restaura el dump en un
  contenedor temporal efímero y compara con SQL real).
- **Seguridad:** 100% solo lectura sobre la BD viva. Contenedor temporal `--rm --network none` +
  `docker rm -f` SIEMPRE (éxito o error); dumps subidos a `/tmp/dbcompare_*.sql` también se borran
  SIEMPRE; `cleanup_all_temp` barre contenedores y dumps huérfanos de ejecuciones abortadas.
  Verificado en producción: **0 contenedores y 0 dumps residuales** tras ejecuciones reales.
- **Bugs corregidos durante la implementación:**
  1. `find_latest_vps_dump` no encontraba dumps de stacks MariaDB (`/data/backups/mariadb-{uuid}/`
     vs `/data/backups/{uuid}/`).
  2. `JSON_OBJECT` de MariaDB se rompía porque los backticks se interpretaban como command
     substitution del host — ahora el SQL se envía por **base64** (patrón `pg_utils::run_pg_query`).

- **Gotchas:**
  - Dos contenedores distintos no pueden hacer `EXCEPT` entre sí → la comparación precisa usa
    **JSON canónico por fila + conjuntos en Rust** (`to_json`/`JSON_OBJECT` por fila, `BTreeSet`
    difference/symmetric_difference). Correcto, determinista y sin parsear el dump como texto.
  - Las columnas `vector` (pgvector) y `bytea` se excluyen de la proyección canónica
    (`comparable_columns()`); tablas solo-vector se marcan `no_comparable`.
  - El dump de PG incluye `set_config('search_path','',false)` — no afecta porque las tablas se
    crean con `public.` explícito.
  - La salida de texto puede truncar líneas largas (muestras JSON); usar `--json` para análisis.
  - El binario canónico se compila en `C:\tmp` (CARGO_TARGET_DIR), no en el árbol (regla AGENTS.md).
