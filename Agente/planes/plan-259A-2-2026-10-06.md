## Deltas API 0.46 → 0.64.1 (verificados docs.rs 06-10)

1. `russh-keys` MUERTO (máx 0.49.2): usar `russh::keys`
   (`load_secret_key`, `PrivateKey`, `PublicKeyOrCertificate`).
2. `Handler::check_server_key(&mut self, _: &PublicKeyOrCertificate)` —
   antes `&key::PublicKey`. Trait ya sin `#[async_trait]` (RPITIT nativo).
3. `authenticate_password/authenticate_publickey` devuelven
   `Result<AuthResult, Error>` — antes `Result<bool, _>`; el `if !auth`
   pasa a `matches!(AuthResult::Success)`.
4. `authenticate_publickey(user, key: PrivateKeyWithHashAlg)` — antes
   `Arc<KeyPair>`; convertir la `PrivateKey` de `load_secret_key`.
5. `client::Config` conserva `inactivity_timeout / keepalive_interval /
   keepalive_max` (mismos tipos) — bloque `connect()` intacto.
6. Features default = `flate2 + aws-lc-rs + rsa`; aws-lc-rs exige cmake
   (ausente en esta laptop) → `default-features = false, features =
   ["flate2", "rsa"]` (rsa puro-Rust, conserva auth RSA). Si el check
   pide proveedor C, fallback `ring` (MSVC presente).
